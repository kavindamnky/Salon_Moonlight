## 🌟 Overview

**MOONLIGHT SALON** is a next-generation digital experience crafted for modern beauty brands. Built with cutting-edge technologies including **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**, this platform combines luxury design, performance optimization, and user-friendly booking systems to enhance client engagement and streamline salon operations.

This platform is designed to reflect elegance, trust, and premium service while ensuring smooth performance across all devices.

- 🎨 **Luxury Design** - Premium white & gold aesthetic

- 🔒 **Type Safe** - Full TypeScript implementation
- 📱 **Mobile First** - Responsive on all devices
- ♿ **Accessible** - WCAG 2.1 compliant

- 💬 **Connected** - WhatsApp integration for instant support

## ⚙️ Installation

> Follow these steps to run **MOONLIGHT SALON** on your local environment:

### Prerequisites

Make sure you have the following installed:
- ✅ **Node.js** (v18.0.0 or higher)
- ✅ **npm** (v9.0.0 or higher) or **yarn** or **pnpm**
- ✅ **Git**
- ✅ **Code Editor** (VS Code recommended)

### Step 1: Clone the Repository

```sh
git clone https://github.com/yourusername/moonlight-salon.git
cd moonlight-salon
```

### Step 2: Install Dependencies

Using npm:
```sh
npm install
```

Using yarn:
```sh
yarn install
```

Using pnpm:
```sh
pnpm install
```

### Step 3: Environment Configuration

Create a `.env` file in the root directory:

```env
# App Configuration
VITE_APP_NAME=Moonlight Salon
VITE_APP_URL=http://localhost:5173
VITE_API_BASE_URL=https://api.moonlightsalon.lk

# WhatsApp Configuration
VITE_WHATSAPP_NUMBER=+94771234567
VITE_WHATSAPP_BUSINESS_ID=your_business_id

# Email Configuration (EmailJS)
VITE_EMAILJS_SERVICE_ID=service_xxxxxxx
VITE_EMAILJS_TEMPLATE_ID=template_xxxxxxx
VITE_EMAILJS_PUBLIC_KEY=your_public_key

# Google Services
VITE_GOOGLE_MAPS_API_KEY=your_google_maps_api_key
VITE_GA_TRACKING_ID=G-XXXXXXXXXX

# Payment Gateway (Optional - Stripe)
VITE_STRIPE_PUBLISHABLE_KEY=pk_test_xxxxxxxxxxxx

# Feature Flags
VITE_ENABLE_BOOKING=true
VITE_ENABLE_PAYMENTS=true
VITE_ENABLE_GIFT_CARDS=true
VITE_MAINTENANCE_MODE=false

# Business Settings
VITE_SALON_PHONE=+94771234567
VITE_SALON_EMAIL=info@moonlightsalon.lk
VITE_SALON_ADDRESS=123 Main Street, Colombo, Sri Lanka
```

> [!IMPORTANT]
> **Security Notice:** Never commit the `.env` file to version control. Use `.env.example` as a template and keep your credentials secure.

### Step 4: Start Development Server

```sh
npm run dev
```

Or with other package managers:
```sh
yarn dev
# or
pnpm dev
```

The application will be available at: **http://localhost:5173**

You should see:
```
  VITE v6.0.5  ready in 250 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

## 🌍 Deployment

### Build for Production

```bash
# Create optimized production build
npm run build
```

This creates a `dist/` folder with optimized static files.

### Deploy to Vercel (Recommended)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

**vercel.json:**
```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite",
  "rewrites": [
    { "source": "/(.*)", "destination": "/" }
  ]
}
```

### Deploy to Netlify

```bash
# Install Netlify CLI
npm install -g netlify-cli

# Deploy
netlify deploy --prod --dir=dist
```

**netlify.toml:**
```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### Deploy to Traditional Hosting

Upload the `dist/` folder contents to your web server.

**Nginx Configuration:**
```nginx
server {
    listen 80;
    server_name moonlightsalon.lk www.moonlightsalon.lk;
    root /var/www/moonlight-salon/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Cache static assets
    location ~* \.(js|css|png|jpg|jpeg|gif|svg|ico|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Gzip compression
    gzip on;
    gzip_vary on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript image/svg+xml;
}
```

### Environment Variables for Production

Set these in your hosting platform:

```env
VITE_API_BASE_URL=https://api.moonlightsalon.lk
VITE_WHATSAPP_NUMBER=+94771234567
VITE_GA_TRACKING_ID=G-XXXXXXXXXX
VITE_MAINTENANCE_MODE=false
```
